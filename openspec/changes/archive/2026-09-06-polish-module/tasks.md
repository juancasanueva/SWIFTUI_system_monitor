## Conventions (every task must respect these)

1. Swift 6, `SWIFT_DEFAULT_ACTOR_ISOLATION = MainActor`: every Domain type, port, adapter, pure model, test double and **nested type** is explicitly `nonisolated` + `Sendable`.
2. Tests are never `@MainActor`; they `await` main-actor members.
3. The sampling loop stays `Task.detached(priority: .utility)`; only `Sendable` values cross.
4. Fakes use `Synchronization.Mutex`; `throwOnCall`/`throwOnSave`/`throwOnEnable`/`throwOnDisable` sets are **zero-based**; record `Thread.isMainThread`.
5. `.timeLimit(.minutes(1))` is the only time limit trait used.
6. Never edit `system-monitor.xcodeproj/project.pbxproj`; new files auto-join via `PBXFileSystemSynchronizedRootGroup`.
7. Widget budget 230 pt (one module < 130 pt); `statusItem.length` is re-measured only when the module set changes, never per value tick.
8. App Sandbox on: `SMAppService.mainApp` and `UserDefaults(suiteName:)` work in the container.
9. Locale pinning `en_US` / `de_DE`, Unicode-aware comparison (map U+00A0 / U+202F to U+0020).
10. Launch-at-login truth is `SMAppService.mainApp.status`, read live, never persisted.
11. Tests never call `register()` / `enable()` / `disable()` on the real adapter; only `.integration` `status` reads.
12. `UserDefaults` tests use a unique `suiteName` per test with `removePersistentDomain(forName:)` cleanup.
13. Settings mutate on the main actor via `SettingsState`; the store port is `nonisolated` + `Sendable`.
14. Every `NSStatusItem` created in tests is removed; every controller is released so `isolated deinit` runs.
15. Do not commit — delivery is user-owned.
16. An Xcode test run re-sorts two `INFOPLIST` keys in `system-monitor.xcodeproj/project.pbxproj`; revert that noise with `git checkout -- system-monitor.xcodeproj/project.pbxproj` and never commit it.
