# Tasks: Disk Module (PRD M5 — "Disk — ship v1")

Strict TDD: every **RED** task writes failing tests naming its spec scenario ids; the paired **GREEN** task adds the minimal production code and ends with a green run. **DOC** tasks touch documentation only. **MANUAL** tasks are executed by the user and their results are recorded in `openspec/changes/disk-module/apply-progress.md`.

Commands:

- `UNIT` = `xcodebuild -project system-monitor.xcodeproj -scheme system-monitor -destination 'platform=macOS' -quiet test -only-testing:system-monitorTests`
- `FULL` = `xcodebuild -project system-monitor.xcodeproj -scheme system-monitor -destination 'platform=macOS' -quiet test` (adds the `.integration` suites in the sandboxed test host)
- `RUN <Suite>` = `UNIT` with `/<Suite>` appended to the `-only-testing` argument (Swift Testing suite type name, not the file name)
- `BUILD` = the same invocation with `build-for-testing` instead of `test`

Sources: `specs/disk-metrics/spec.md` (DM-1..DM-15, 42 scenarios), `specs/disk-card/spec.md` (DC-1..DC-11, 25 scenarios), `design.md` (interfaces, decision table and per-requirement test mapping are normative), `proposal.md` (conventions 1–19). Traceability: 67 scenarios.

## Conventions (every task respects these)

1. Every Domain type, port, adapter, formatter, pure model, test double and **nested type** is explicitly `nonisolated` + `Sendable`; only `MetricsState`, `MetricsSampler`, views and controllers are main-actor.
2. Tests are never `@MainActor`; they `await` main-actor members.
3. `.timeLimit(.minutes(1))` is the only time-limit trait; every new loop suite carries it (convention 5 — the design does not repeat it).
4. Fakes use `Synchronization.Mutex`; `throwThroughputOnCall`/`throwCapacityOnCall` are zero-based; both reads record `Thread.isMainThread`.
5. Loop suites run on `ManualClock`; cadence and rate scenarios run through `sampleOnce()` with scripted `ContinuousClock.Instant`s derived from one base — never wall-clock sleeps (convention 19).
6. Never edit `system-monitor.xcodeproj/project.pbxproj`; new files auto-join via `PBXFileSystemSynchronizedRootGroup`. If a test run re-sorts `INFOPLIST` keys there, revert that noise and never commit it.
7. Locale strings are pinned under `en_US` and `de_DE` with the U+00A0/U+202F normaliser reused from `ByteFormatterTests`.
8. Every IOKit handle is released in a `defer`; a matching dictionary passed to `IOServiceGetMatchingServices` is consumed and never released by the caller.
9. Do not commit — delivery is user-owned.
