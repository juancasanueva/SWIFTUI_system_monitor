# Tasks: Network Module (PRD M6 — "Network")

Strict TDD: every **RED** task writes failing tests naming its spec scenario ids; the paired **GREEN** task adds the minimal production code and ends with a green run. **DOC** tasks touch documentation only. **MANUAL** tasks are executed by the user and their results are recorded in `openspec/changes/network-module/apply-progress.md`.

Commands:

- `UNIT` = `xcodebuild -project system-monitor.xcodeproj -scheme system-monitor -destination 'platform=macOS' -quiet test -only-testing:system-monitorTests`
- `FULL` = `xcodebuild -project system-monitor.xcodeproj -scheme system-monitor -destination 'platform=macOS' -quiet test` (adds the `.integration` suites in the sandboxed test host)
- `RUN <Suite>` = `UNIT` with `/<Suite>` appended to the `-only-testing` argument (Swift Testing suite type name, not the file name)
- `BUILD` = the same invocation with `build-for-testing` instead of `test`

Sources: `specs/network-metrics/spec.md` (NM-1..NM-13), `specs/network-card/spec.md` (NC-1..NC-13), `specs/disk-card/spec.md` (delta DC-1, DC-11), `design.md` (interfaces, decision table and per-requirement test map are normative), `proposal.md` (conventions 1–14). Every task binds the spec's final ids verbatim.

## Conventions (every task respects these)

1. Every Domain type, port, adapter, pure model, test double and **nested type** is explicitly `nonisolated` + `Sendable`; only `MetricsState`, `MetricsSampler`, views and controllers are main-actor.
2. Tests are never `@MainActor`; they `await` main-actor members. `.timeLimit(.minutes(1))` is the only time-limit trait.
3. Fakes use `Synchronization.Mutex`; `throwOnCall` is zero-based; every read records `Thread.isMainThread`.
4. Loop suites run on `ManualClock`; rate scenarios run through `sampleOnce()` with scripted `ContinuousClock.Instant`s derived from one base — never wall-clock sleeps.
5. Never edit `system-monitor.xcodeproj/project.pbxproj`; new files auto-join via `PBXFileSystemSynchronizedRootGroup`. Revert any `INFOPLIST` re-sort noise a test run leaves there.
6. Locale strings are pinned under `en_US` and `de_DE` with the U+00A0/U+202F normaliser reused from `ByteFormatterTests`.
7. `sysctl` constants and struct names come from `Darwin` with header citations (`NET_RT_IFLIST2` `sys/socket.h:541`, `RTM_IFINFO2` `net/route.h:214`); the buffer is sized by a nil-buffer call, allocated once per read and walked with `loadUnaligned` — never a typed pointer cast.
8. `HistoryGraph` series colours are Presentation tokens; `MetricsState` never sees a colour, a unit or a normalised value.
9. Do not commit — delivery (commit, push, PR) is user-owned. Batches A–G below are work-unit commit boundaries the user may use.
